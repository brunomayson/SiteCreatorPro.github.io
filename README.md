# AccessCore Sentinel — Controle de Acesso Empresarial

Protótipo SaaS local, visual e funcional para demonstração comercial de controle de acesso empresarial.

**Desenvolvido por:** Bruno Mayson  
**LinkedIn:** https://www.linkedin.com/in/brunomayson/

## Proposta

O AccessCore Sentinel demonstra um sistema corporativo para gestão de visitantes, empresas, funcionários, veículos, códigos de acesso, permissões, catracas, terminais, coletores, redes, entrada/saída e relatórios.

Ele foi criado para apresentações comerciais: abre direto no navegador, tem dados demonstrativos e simula o fluxo completo de uma portaria moderna.

## Como usar

1. Abra o site publicado no GitHub Pages.
2. Entre em **Guia de Uso** para ver o roteiro comercial.
3. Abra **Visitantes** e clique em **Novo registro**.
4. Cadastre o visitante e copie o código gerado.
5. Abra **Coletor**, informe o código ou documento e simule entrada/saída.
6. Confira o registro em **Entrada/Saída**.
7. Abra **Relatórios** para exportar CSV ou JSON.
8. Use **Configurações** para tema, backup, importação e reset.

## Observação de segurança

Este projeto é um protótipo front-end. Ele não deve ser usado como sistema real de segurança. Uma versão de produção exigiria backend, banco de dados, autenticação segura, RBAC no servidor, API, criptografia, logs auditáveis, backup e integração física com catracas/coletoras.
